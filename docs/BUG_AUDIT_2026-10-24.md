# ContextOS 버그 점검과 수정 — 2026-10-24

이 점검은 현재 macOS 로컬 앱의 실제 사용 흐름을 기준으로 했다. 코드 조회·본문 전달, 로컬 사용량 집계, 날짜와 개발 기록, AI 연결 설정, 앱 화면, 위젯 공유를 확인했다. 기존 작업 내용을 보존한 상태에서 오류를 재현하고 수정했으며, 아래 검증 결과는 이번 실행에서 다시 확인한 값이다.

## 검증 결과

- macOS 테스트: 467개 중 **464개 통과**, Windows 전용 3개 건너뜀, 실패 0개. 이번 점검의 회귀 검사는 18개 추가했다.
- portable 준비 프로필: 15개 통과, 해당 환경에서 실행할 수 없는 5개 건너뜀. 실제 Windows 제품 전체를 검증한 결과는 아니다.
- 편집기 브리지: 단위 검사 10개와 실제 Unix 소켓 통합 검사 1개 통과. 통합 검사의 편집기 API와 시계는 합성 입력이다.
- 실제 MCP: 도구 목록 6개, 정상 본문 전달·중복 생략·강제 재전달·예산·강제 재색인·보호 파일 경계·잘못된 요청 복구 확인.
- 교차 파일 의존성: 200~250 추정 토큰에서 6/6 필수 구현 전달, 모두 예산 이내, 무관한 구현 본문 미포함.
- 현재 소스의 고정 질의 12개: 핵심 파일 12/12 첫 순위 및 전달. 작은 예산 정보 보존 4/4. 이는 정해 둔 질의의 소스 검색 검사이며 일반적인 AI 과업 정확도 점수가 아니다.
- 넓은 질의 7개는 예산보다 필수 코드가 많아 부족한 위치를 표시했다. 누락 안내를 완전한 전달로 계산하지 않는다.
- 연결 설정 변경·취소·해제·복구는 임시 사용자 환경에서 검증했다. 실제 사용자 연결 설정을 시험용으로 덮어쓰지 않았다.
- 실제 사용자 사용량 DB의 읽기 전용 `quick_check` 결과는 `ok`. 원본 로그와 기록을 보존하고 잘못된 파생 캐시만 다시 계산했다.

## 설치 확인

최종 설치본은 **2.1.0, 빌드 2127**이며 경로는 `/Applications/ContextOS.app`이다. 설치한 앱과 CLI·MCP·위젯 실행 파일의 해시가 서명한 후보와 일치하는지, 호스트와 위젯 버전·App Group·서명·위젯 등록이 올바른지 확인했다. 점검 중 대시보드·AI 사용량·개발 시간의 실제 화면을 확인했다. 최종 설치 후 앱 실행, 대시보드, 연결 설정의 직접 표시와 실제 공유 집계 저장까지 확인했다. 수동 새로고침으로 실제 공유 파일이 갱신되고, 잠금 해제 후 네이티브 위젯의 표시와 접근성 집계가 앱 집계와 일치함을 확인했다. 실제 사용량 수치는 로컬 검증 기록에만 보관한다.

**화면 검증 완료:** Mac 잠금 해제 후 Claude·Codex 연결 미리보기를 열고 취소했다. 실제 Codex 설정·지침·관리 기록의 해시가 미리보기 전과 같았다. 다른 페이지에서 설정 재진입, 원래 화면 복귀, 수동 새로고침과 위젯 표시를 확인했으며 개인 정보 숨김을 켜짐으로 복원했다. 실제 설정 적용 버튼은 누르지 않았다.

이전에 열어 둔 AI 대화의 MCP 프로세스는 설치 전 코드로 계속 실행될 수 있다. 새 연결은 설치된 실행 파일을 사용하며 실제 호출로 검증했다. 진행 중인 다른 대화를 끊는 일괄 종료는 수행하지 않았다.

이 점검은 현재 macOS 환경과 지원하는 로컬 기록 형식에 대한 결과다. 모든 OS 버전·기기·미래 로그 형식에 버그가 전혀 없다는 보장은 아니다. 온라인 청구 내역이나 다른 기기의 사용량과 일치하는 수치로 해석하면 안 된다.

합성 입력의 회귀 검사와 요약 결과는 [공개 검증 자료](benchmarks/bug-audit-20261024/)에 있다. 실제 사용량·DB 집계·설치 및 UI 원자료와 실행 로그는 로컬 전용으로 보관하며 저장소에서 제외한다. 공개 범위는 [검증 자료 안내](benchmarks/README.md)를 따른다.

프로토콜 오류 응답과 Git 경로 구분 동작은 [JSON-RPC 2.0](https://www.jsonrpc.org/specification), [Git status](https://git-scm.com/docs/git-status), [Git log](https://git-scm.com/docs/git-log)의 공식 계약을 기준으로 확인했다.
