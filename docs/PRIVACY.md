# 개인정보와 로컬 데이터

ContextOS는 자체 LLM API, 원격 서버, 계정, 결제, 텔레메트리, 자동 업데이트 요청을 사용하지 않습니다. 실행 중 소스 분석·검색·기록 집계는 로컬에서 처리합니다. 소스 빌드 시 SwiftPM 의존성 다운로드, 사용자가 실행하는 GitHub 작업, 선택적 Developer ID 서명·공증은 별도의 개발 작업입니다.

## 읽는 데이터

- 사용자가 MCP·CLI로 지정한 프로젝트의 허용된 소스 파일, 심볼·import 정보, `.gitignore`, Git 상태·커밋.
- 프로젝트 규칙 파일과 사용자가 전달한 검색 요청.
- 메뉴바 대시보드의 사용량·활동 표시를 위해 Claude Code와 Codex가 남긴 로컬 JSONL 세션 기록. 스트리밍 파서가 작업 경로·시간·사용량·활동 이벤트를 집계합니다. 이 로그 자체에 대화·도구 출력이 들어 있을 수 있으며, ContextOS가 해당 로그를 읽는다는 점에 동의하는 사용 흐름이 필요합니다.
- 연결 미리보기·적용 시 해당 도구의 설정과 지침 파일. 백업은 기존 파일 전체를 포함할 수 있습니다.

선택된 코드와 규칙은 stdio MCP 또는 Claude 훅을 통해 **연결한 AI 에이전트에 전달**됩니다. 그 에이전트가 모델 공급자에게 보내는 데이터는 에이전트의 설정과 개인정보 정책을 따릅니다. “ContextOS에 자체 서버가 없다”는 것이 “AI 사용 중 코드가 외부로 나가지 않는다”는 보장은 아닙니다.

## 쓰는 데이터와 위치

| 위치 | 저장 내용 |
|---|---|
| 각 프로젝트 `.contextos/index.sqlite`와 WAL/SHM | 파일 경로·해시·크기·수정시각·심볼·import 인덱스. 일반 소스 본문 전체를 저장하는 구조는 아님 |
| 각 프로젝트 `.contextos/` | 훅의 세션 중복 제거 상태 등 파생 자료 |
| `~/Library/Application Support/ContextOS/usage.sqlite`와 WAL/SHM | 최적화 요청·프로젝트 경로·추정 토큰·실제 도구 로그의 집계 캐시·부채 스냅샷 등 |
| `~/.contextos-backups/` | 변경 전 설정 전체, 연결 관리 기록, 로컬 잠금 파일 |
| 앱 UserDefaults | 메뉴바 표시·마스코트 동작 등 UI 선호 설정 |
| Claude/Codex 설정·지침 | 적용을 선택한 ContextOS MCP·훅·마커 지침 항목 |

최적화 요청은 로컬 사용 기록에 남을 수 있습니다. 민감 파일 참조는 가리지만 요청 문장 자체에 포함된 비밀번호·개인정보를 완전히 탐지하는 기능은 없습니다. UI와 백업을 공유하기 전 내용을 확인하세요. 앱 사용 기록과 백업은 자동 만료되지 않으며, 앱을 제거해도 남습니다. 원래 AI 도구 로그는 삭제하지 않습니다.

## 기본 제외와 한계

`.env`·`.env.*`·`*.env`, 자격증명 JSON/YAML, 개인 키·인증서 파일, `.ssh`·`.aws` 같은 경로는 인덱싱·본문 전달에서 기본 제외합니다. 디렉터리마다 `.gitignore`를 적용하고 부모 규칙·자식 negation의 범위를 구분합니다. 제외된 부모 디렉터리는 내려가지 않습니다. 민감 파일은 negation으로 다시 포함할 수 없습니다.

이 정책은 **파일명과 경로에 의한 보호**입니다. 일반 Swift/Python 파일에 하드코딩한 비밀을 완전히 탐지하지 못합니다. 규칙 파일에도 비밀을 넣지 마세요. 프로젝트 소스를 선택해서 에이전트에 전달하는 프로그램이라는 점을 고려해 프로젝트의 `.gitignore`를 관리해야 합니다.

소스·규칙·ignore 파일은 프로젝트 기준 디렉터리 핸들을 따라 읽고 심볼릭 링크와 특수 파일을 거부합니다. 기본 읽기 한도는 파일당 2MB입니다. 규칙 파일이 프로젝트 밖이나 민감 파일을 가리키는 링크여도 전달하지 않습니다. 민감 디렉터리 아래를 프로젝트 루트로 지정하거나 인덱스 디렉터리·DB·sidecar에 링크가 있으면 인덱싱을 중단합니다. 백업 폴더·파일 권한은 제한하지만 디스크 암호화나 동일 사용자 계정의 악성 프로그램으로부터의 보호를 대신하지 않습니다. 설정 동시 수정이 감지되면 덮어쓰기를 중단합니다.

## 데이터 정리와 문의

연결 해제를 먼저 완료하고 앱·AI 도구를 종료한 뒤 사용자가 원하는 프로젝트 인덱스, 전역 파생 기록, 백업을 별도로 정리할 수 있습니다. 백업을 지우면 이전 설정으로의 복구와 소유권 확인에 필요한 기록도 사라집니다. 자동 업로드·자동 지원 수집 기능은 없습니다. 지원 채널과 절차는 [설치 문서](INSTALL.md)를 참고하세요.
