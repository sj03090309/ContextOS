# Main dashboard design, build 2111

The menu-bar dashboard now keeps observed AI usage and development activity in one bounded popover. Its information order is today's observed tokens, development activity, estimated ContextOS savings, and historical records. Usage and time details remain inside the same popover.

The existing ink/cream mascot identity is retained with a quieter header, a sliding selected tab, restrained press and hover feedback, inline disclosures, and explicit loading, missing and zero states. The default mascot setting is still while idle and moves when actual work signals exist; an explicitly saved motion preference is preserved. System Reduce Motion suppresses interface motion and mascot animation, including the menu-bar renderer. The mascot retains a separate hosting tree so its frames do not invalidate the calendar. The time controller is observed by its cards rather than by the entire dashboard.

Privacy display starts enabled for this release preview. It substitutes project labels, hides paths and project logos, hides recent query text and connection details, and leaves all underlying records and numbers intact. It does not protect other windows opened outside the dashboard. App-menu shortcuts Command-1/2/3 select the three pages, and focused segments support left/right navigation. Escape retains native popover dismissal; the settings overlay handles Escape while open.

The container resolves its size before display, instead of feeding an unbounded fitting size back into NSPopover. Content scrolls within that size. Actual build 2111 was observed on a 1920×1080 screen at 1×: popover bounds (1325,26,366,786), center x=1508, matching its own status item's center x=1508. The full mascot face, integrated usage page, privacy display and limited-accounting notice were visually inspected in an app-window-only capture. No full-display capture was used.

Validation: Release build passed; 93 XCTest, 58 usage tests, 205 core tests and 5 dashboard tests passed (361 total). Native offscreen review renders covered dark/light appearances, 440/760pt heights, settings on the compact layout, missing/zero/loading/long-name states, and private/public display with synthetic project/query data. Synthetic images are marked as examples and are not demonstration footage. The installed 2.1.0/2111 bundle passed normal-environment signature validation with the existing team and exact approved App Group. Existing widget payload, CLI and MCP were retained. The prior 2110 bundle was kept for restore.

Limits: CUA cannot bind the native AXPopover (AXWindows is empty), so physical internal clicks, hover/press timing, rapid transitions, keyboard shortcuts, Escape/click-away dismissal and physical movement to a smaller screen have not been verified. The rapid-switch test validates retained UI state, not physical input or animation timing. Reduce Motion policy is tested and wired to system changes; toggling the OS setting live was not tested. No long-duration CPU or battery claim is made. No new screen permission, account, public deployment or collector was added. Full dot/cloud token coverage remains unsupported.

Evidence is retained in the task workspace under qa/contextos-design-*.log, qa/contextos-design-postinstall.json, qa/design-review/, and deliverables/ContextOS-*-design-example.png. Temporary screen-keepalive assertions were released after actual screen QA. Video remains pending actual permitted interactions.
