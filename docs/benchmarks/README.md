# 검증 자료 공개 범위

이 폴더에는 재실행 가능한 합성 입력의 품질·성능 측정, 회귀 검사 결과, 검증한 소스 해시와 민감값을 제외한 요약을 보관한다. 수치는 명시한 입력·빌드·실행 환경에서의 결과이며 일반적인 답변 정확도, 실제 청구 절감액이나 배터리 효과를 보장하지 않는다.

실제 사용자 사용량과 기기별 원자료는 로컬 전용이다. 원시 실행 로그, 작업 트리 패치, 설치·UI·정리 JSON, 실제 사용량 대조 JSON 및 기기 경로를 담은 초기 감사 요약은 `.gitignore`로 제외한다. 공개 보고서는 구체적인 사용자 토큰 수·요청 수·개인 경로 대신 검증한 동작과 일치 여부만 설명한다.

2026-10-22~24 감사 자료의 공개 전 원본은 무시되는 `.audit/prepublish-20261103/private-evidence/`에 복사해 보존했다. 제외한 파일을 보고서에서 언급하는 경우 로컬 검증 증거를 뜻하며, 저장소의 공개 링크가 아니다. 재검증 때에는 합성 입력과 임시 홈을 우선 사용하고 실제 계정 기록이 출력된 결과를 추가하지 않는다.
